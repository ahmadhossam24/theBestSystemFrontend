data is unified across all tables for default columns 
so in datasets table the data will be displayed normally default and extra columns data will be displayed
there is transferring data from dataset and general tables to general tables only (cant transfer to dataset table) feature
in general tables also default and extra columns of that general table will be displayed, and there is datasettable type filter when user choose a type the extra columns of this dataset table appears
you might have a question what if user transferred data from general to general table -> in this case the extra columns data added from first general table will be ignored will not be displayed. what will be displayed only will be extra data of the dataset table type of this row 
here you might have a question what if i want extra data that appears in general table to appear also in other general table when row transferred to ? answer is : that case means that you should make this col as default col applied on all tables so it will appear in all tables
